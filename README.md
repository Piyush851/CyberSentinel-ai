# 🛡️ CyberSentinel AI

> **Detecting threats. Explaining decisions. Protecting humans.**

CyberSentinel AI is a proactive, hybrid Machine Learning (ML) platform designed to detect phishing URLs and fraudulent SMS messages in real-time. Moving beyond traditional "black-box" security, CyberSentinel integrates **Explainable AI (XAI)** to deconstruct its decisions, providing human-readable reasoning to build user trust and digital literacy.

---

## ✨ Core Features

* 🔗 **URL Analysis Engine:** Evaluates lexical structure, domain reputation, and protocol security using a Random Forest classifier.
* 📩 **SMS Semantic Scanner:** Uses Natural Language Processing (NLP) to detect coercion, urgency, and financial bait in text messages.
* 🧠 **Explainable AI (XAI):** Deconstructs risk scores into visual feature weights and human-readable tags (e.g., *"Suspicious urgency detected"*, *"Uses raw IP address"*).
* 🛡️ **Hybrid Defensive Architecture:** Implements a multi-layered detection strategy: ML Pipeline -> Structural Override Rules -> Heuristic Fallback.
* 📊 **Threat Intelligence Dashboard:** Real-time data visualization of scanned assets, verdict breakdowns, and active threat logs.

## 🛠️ Tech Stack

**Frontend (Client)**
* React 19 + Vite
* React Router DOM (SPA Routing)
* Axios (Network Requests & Error Handling)
* Tailwind CSS (Styling)

**Backend (API Engine)**
* Python 3
* FastAPI + Uvicorn (Async API Gateway)
* Scikit-Learn `1.7.1` (ML Models: Random Forest, Logistic Regression, TF-IDF)
* Joblib (Model Serialization)
* Pytest + HTTPX (Testing Suite)
